# Dynasty Engine

An external front-office / GM tool for a CFB27 dynasty — recruiting, the
transfer portal, and NIL, driven **outside** the game, with CFB27's own
in-game recruiting/portal systems modded off. A companion **Dynasty Engine
mod** (`.fbmod`, distributed as a [release](../../releases) here) zeroes
in-game recruiting hours so the tool is the only way to scout, offer, and
sign.

This repo is the **public side** of the project: releases, bug reports,
feature requests, questions, and the wiki. The app's source code lives in a
separate private repo — this one exists so anyone can get the tool, report
a problem, and find answers without needing access to the source.
