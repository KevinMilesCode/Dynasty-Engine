# FAQ

> Reading this on GitHub's Code tab instead of a Wiki tab? That's expected —
> see the note on [Home](Home.md) for why.

Entries below are added by hand — not by CI automation. When a question in
[Discussions → Q&A](https://github.com/KevinMilesCode/Dynasty-Engine/discussions/categories/q-a)
gets answered, it's folded into this page manually (typically with Claude
Code's help, working locally against a clone of this repo — see
`MAINTAINING.md`), then committed and pushed. Pushing to `main` is what
publishes it to the actual GitHub Wiki (`.github/workflows/wiki-sync.yml`
mirrors this file over, no AI involved in that step) once the Wiki feature is
turned on. This page is never edited directly on github.com/.../wiki — those
edits get overwritten by the next sync.
