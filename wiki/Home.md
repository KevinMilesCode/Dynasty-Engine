# Dynasty Engine Wiki

Community-maintained reference for the CFB27 Dynasty Engine app and mod.

> **Reading this in the repo, not on a Wiki tab?** That's expected for now.
> GitHub only offers Wikis on private repos with a paid plan, and this repo
> is private until public release, so the Wiki feature isn't turned on yet.
> The [`wiki/`](https://github.com/KevinMilesCode/Dynasty-Engine/tree/main/wiki)
> folder here is the real thing in the meantime — same content, same
> process. Once the repo goes public (free tier includes Wikis for public
> repos) or moves to a paid plan, this same content mirrors over to a real
> Wiki automatically (`wiki-sync.yml`) and this note goes away.

**Source of truth:** this wiki is generated from the
[`wiki/`](https://github.com/KevinMilesCode/Dynasty-Engine/tree/main/wiki)
folder in this repo. Once the real Wiki is live, don't edit pages directly on
github.com/.../wiki — edits made there get overwritten by the next sync.
Instead, open a pull request against `wiki/*.md` here; once merged, it's
mirrored there automatically.

## Pages

- [About.md](About.md) — what Dynasty Engine is, why it exists, how it
  works, features, and the longer-term vision
- [Status.md](Status.md) — what's currently in progress or not built yet
  (a snapshot, updated by hand)
- [FAQ.md](FAQ.md) — common questions, curated by hand from answered
  [Discussions](https://github.com/KevinMilesCode/Dynasty-Engine/discussions/categories/q-a)

## Getting help

- **Bug?** [Open an issue](https://github.com/KevinMilesCode/Dynasty-Engine/issues/new?template=bug_report.yml)
- **Feature idea?** [Open an issue](https://github.com/KevinMilesCode/Dynasty-Engine/issues/new?template=feature_request.yml)
- **Question?** [Ask in Discussions → Q&A](https://github.com/KevinMilesCode/Dynasty-Engine/discussions/categories/q-a) —
  answered questions get folded into the [FAQ](FAQ.md) manually (see
  `MAINTAINING.md`), not by an automated bot.
